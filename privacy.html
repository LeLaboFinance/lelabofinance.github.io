Privacy Policy

Last updated: November 24, 2026

This policy applies to the "Robot Labo Finance" application (the "application"), the internal tool that uploads and schedules videos for the Le Labo Finance YouTube channel, and to this website.

1. YouTube API Services

The application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

2. Who uses the application

The application is used only by the operator of the Le Labo Finance channel, for its own YouTube account. It is not offered to the public and does not request access to any other account.

3. Data accessed and how it is used

With the authorization granted by the channel owner through Google OAuth, the application:

  • reads the name and ID of the authorized channel, to confirm it publishes to the right channel;
  • reads the list of that channel's videos and their status (title, private or public), to find the videos to finalize;
  • uploads videos produced by Le Labo Finance;
  • sets their titles, descriptions, translations, tags, thumbnails and publication date.

It does not read comments, messages, subscribers, analytics, watch history or personal data of other users.

4. Storage, security and sharing

  • The authorization token is stored encrypted in the secrets of the private repository that runs the application.
  • Data received from YouTube is used only while the application runs. Run logs are deleted automatically after 30 days at most.
  • No data is sold, shared, transferred to third parties or used for advertising.

5. Cookies

Neither the application nor this website places, accesses or recognizes cookies or tracking tools on your device. The website is hosted by GitHub Pages, which may process technical connection data under the GitHub General Privacy Statement.

6. Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deleting data

Access can be revoked at any time through the Google security settings page: security.google.com/settings/security/permissions. After revocation, the application can no longer access the account and the stored token is deleted.

To request data deletion, write to the address below: data will be deleted within 7 days.

8. Changes

Any change to this policy will be published on this page with its update date.
