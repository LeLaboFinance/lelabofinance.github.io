Privacy Policy

Last updated: November 24, 2026

This policy applies to the "Robot Labo Finance" application (the "application"), the internal tool that uploads and schedules videos for the Labo Finance YouTube channel.

1. Who uses the application

The application is used only by the operator of the Labo Finance channel, for its own YouTube account. It is not offered to the public and does not request access to any other account.

2. Data accessed

With the authorization granted by the channel owner through Google OAuth, the application uses YouTube API Services to:

  • upload videos produced by Labo Finance;
  • set their titles, descriptions, translations, thumbnails, tags and publication date;
  • read the ID and status of the videos it uploaded.

It does not read messages, subscribers, watch history or personal data of other users.

3. Storage and security

The authorization token is stored encrypted in the secrets of the private repository that runs the application. No user data is sold, shared, transferred to third parties or used for advertising.

4. Google services

The application uses YouTube API Services. By using it, you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access

Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions. To request data deletion, write to the address below.
